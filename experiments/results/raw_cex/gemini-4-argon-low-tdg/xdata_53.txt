-- DATASET 2
-- Tests the un-correlated nature of the outer EXISTS in the Gold Query, and tests duplicate elimination / multiple teaches per instructor.
-- Here, Instructor 10101 teaches 2 sections, Instructor 12121 teaches 1 section, and Instructor 15151 teaches 0 sections (and has a NULL dept_name).
-- Because the Gold Query has an uncorrelated EXISTS (checking only if t1.ID = t2.ID exists anywhere in `teaches`), ALL 3 instructors are returned once.
-- This kills mutants that:
-- 1. Correlate the subquery with `instructor.ID` (e.g., WHERE instructor.ID = t1.ID), which would exclude 15151.
-- 2. Use INNER JOIN without DISTINCT, which would duplicate 10101 and exclude 15151.
-- 3. Require an instructor to teach multiple distinct sections (e.g. t1.sec_id <> t2.sec_id), which would exclude 12121 and 15151.
-- 4. Inner join with `department`, which would exclude 15151 due to NULL dept_name.
