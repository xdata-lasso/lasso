--    If integer division is used, 'Item_Two' (price 2) is falsely included (2 <= 2).
-- 2. Duplicate product_prices skewing the average ( testing AVG(product_price) vs AVG(DISTINCT product_price) ).
--    Prices: 1, 1, 2, 4 -> sum = 8, count = 4, avg = 2.0. Distinct prices: 1, 2, 4 -> avg = 2.3333.
--    Here we use 1.0, 2.0, 4.0, 4.0 -> AVG = 11/4 = 2.75, AVG(DISTINCT) = 7/3 = 2.333.
