-- Tests NULL Consumption handling and COUNT(T2.Consumption) vs SUM(T2.Consumption) mutants.
-- In SQLite, NULLs are considered smaller than any non-NULL value in ASC order.
-- C2 has NULL consumption -> SUM(Consumption) is NULL, which sorts first in ASC.
-- C1 has 0.0 consumption -> if a mutant uses COALESCE(Consumption, 0) or filters IS NOT NULL, or uses COUNT(), C1 might win or tie differently.
-- C3 has negative consumption (-10.0) -> tests signed ordering vs NULL ordering.
