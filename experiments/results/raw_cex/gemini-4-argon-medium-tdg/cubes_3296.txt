-- DATASET 2
-- Tests NULLS LAST on tweets.id when text values are identical, 
-- and NULL handling on text (NULLS FIRST by default in SQLite ASC ordering).
-- Note: In SQLite, INTEGER PRIMARY KEY allows a single NULL unless STRICT or NOT NULL is specified, 
-- or if the column is declared as INTEGER(20) PRIMARY KEY (which is not an alias for rowid, thus allowing NULL).
